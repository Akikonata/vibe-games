🎮 操作说明与出招表

1P 按键 (左侧)

  • 移动 / 跳跃 / 下蹲： A D W S
  • 轻拳 / 轻脚： J / K（可连打起手）
  • 重拳 / 重脚： U / I（高伤 / 扫腿击倒）
  • 紧急回避 (翻滚)： L（短暂无敌，穿波脱身）
  • 超必杀 (消耗1气)： O
  • 防御： 按住后退方向（下蹲+后退防下段）

2P 按键 (右侧 · PVP)

  • 移动 / 跳跃 / 下蹲： ← → ↑ ↓
  • 轻拳 / 轻脚： Num1 或 N / Num2 或 M
  • 重拳 / 重脚： Num4 或 , / Num5 或 .
  • 紧急回避 (翻滚)： Num3 或 /
  • 超必杀 (消耗1气)： Num6 或 ;
  • 防御： 按住后退方向（下蹲+后退防下段）

🔥 必杀技出招方式（支持传统搓招 + 快捷方向）

必杀技 1 (飞行道具/波动) 搓招 ↓↘→ + 拳 或快捷 前 + 重拳
必杀技 2 (对空升龙/无敌) 搓招 →↓↘ + 拳 或快捷 上/下 + 重拳
必杀技 3 (突进连击) 搓招 ↓↙← + 脚 或快捷 前/后 + 重脚
MAX 超必杀 (需1格气) 按 O (1P) 或 Num6 / ; (2P)
